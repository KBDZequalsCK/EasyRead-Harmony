# EasyRead for HarmonyOS 使用说明

本说明对应当前源码版本 1.1.0，适用于 HarmonyOS 平板、2-in-1 与手机（系统 API 12 及以上）。界面文案可能随版本略有调整，请以应用内实际显示为准。

## 安装与首次启动

### 安装

本仓库只提供源码，**不提供可以直接下载安装的 HAP**。HarmonyOS 安装包必须使用华为开发者证书和匹配的 profile 签名，普通用户不能像安装 APK 一样侧载。

最简单的安装方式是在 DevEco Studio 中打开项目，配置自动签名，连接设备后运行 `entry` 模块。完整的环境要求、签名步骤和命令行构建方法见 [README 的「构建与安装」](../README.md#构建与安装)。

### 首次启动与隐私同意

首次启动会显示隐私政策。应用在你点击「同意并继续」之前不会加载书库、阅读进度或 WebDAV 账号，也不会联网。

- 「同意并继续」：进入书架，之后可以正常导入和阅读。
- 「不同意」：应用显示无法使用的提示页，可以重新阅读隐私政策或退出。

同意后，如果上次离开应用时还停留在阅读页，应用会尝试回到那本书；如果上次已经退回书架，则从书架开始。窄屏阅读时，返回键会先关闭面板或搜索，再回到书架；在书架上再按一次返回才会退出应用。

## 书架

### 从文件导入

点击书架右上角的「+」，从系统文件选择器选择书籍。单次最多选择 20 个文件，支持以下扩展名：

```text
.txt .md .markdown .epub .pdf .mobi .azw .azw3 .fb2 .cbz .rtf .docx
```

导入会把书籍复制到 EasyRead 的应用沙箱，不会移动或修改你在系统文件管理器中选中的原文件。相同书籍（书名、格式和大小相同）已经在当前书架时会被跳过；如果最终没有导入任何新书，应用会提示「没有导入新书（可能已在书架中）」。

**导入目标由当前书架决定**：停在「本地书库」时导入的书进入本地书架；停在「WebDAV书库」时导入的书进入 WebDAV 书架。后者会被视为云端书库的一部分，并可能在同步时上传到 WebDAV。**WebDAV 同步只处理 WebDAV 书架里的书，本地书库不会自动上传。**

### 关联本地文件夹

在「本地书库」标签旁点击文件夹图标，可以选择一个本地文件夹作为书库目录。应用会递归扫描该文件夹及其子文件夹，把支持格式的书批量导入书架。

- 文件夹访问权限会被持久化，下次启动时应用可以继续重新扫描。
- 关联文件夹后，点击旁边的刷新图标或下拉书架即可重新扫描，用于发现新增书籍。
- 再次选择一个文件夹会替换当前关联目录；之前已经导入的书仍留在书架中。
- 应用只读取关联目录中的书籍并复制到沙箱，不会改写或删除原目录中的文件。
- 如果设备不支持选择文件夹，应用会提示改用多文件导入。

### 浏览与搜索

书架顶部有「本地书库」和「WebDAV书库」两个标签，标签上的数字是各自的书本数量。两个书库都可以直接使用，不需要解锁或购买。

- 右上角按钮可以在网格视图和列表视图之间切换。
- 搜索框「搜索书名或作者」只匹配书名和作者，不搜索书籍正文。
- 书架默认按最近阅读时间排序，当前打开的书会排在最前面。
- 宽屏设备（约 720vp 及以上）可以把书架和阅读器并排显示，并用侧栏按钮收起或展开书架。

下拉书架可以刷新：本地书库会重新扫描已关联的文件夹；WebDAV 书库会执行一次双向同步。没有关联文件夹时，下拉只刷新当前列表。

### 书籍菜单与删除

在网格视图中长按封面，或在列表视图中点击右下角的「⋯」（也可以长按列表项），可以打开书籍菜单。

本地书籍的菜单包括：

- **打开**：进入阅读器。
- **移出书架**：移除书架记录，不删除书籍文件；这本书的书签和笔记会一并移除。
- **删除本地文件**：删除 EasyRead 沙箱中保存的书籍副本并移出书架；你在系统文件管理器中的原文件不受影响。

WebDAV 书籍的菜单包括：

- **打开**：进入阅读器。
- **删除本地副本**：只删除本机副本，云端文件（如果存在）仍然保留；已同步到云端的书会在下次同步时重新下载。本书的书签和笔记会一并移除，且不会随书恢复，因为书签和笔记不参与 WebDAV 同步。
- **从云端删除并移出书架**：尝试向云端写入删除快照，并移除本机和书架记录；云端找不到这本书时只移除本机记录。其他使用同一 WebDAV 书库的设备在下次同步时也会移除这本书。此操作不能在同步进行中执行。

删除操作会同时清理该书的书签和笔记，应用没有回收站。如果这本书你还想继续阅读，请先保留原始文件或云端副本。

## 阅读

### 打开与翻页

点击书籍即可打开。首次打开或重新排版时，文字书会显示「正在排版…」，较大的书需要稍等。

阅读时轻点页面中部可以隐藏或显示工具栏与底部进度条。文字书的工具栏提供：

- 「⇆ 翻页 / ↕ 滚动」：切换左右分页和上下滚动。
- 目录、搜索、书签、笔记和阅读设置。
- 窄屏用返回按钮回到书架；宽屏用侧栏按钮和关闭按钮。

左右分页模式下，可以左右滑动翻页，也可以使用外接键盘的方向键、PageUp、PageDown 或空格键。上下滚动模式按正常滚动阅读。两种模式切换时会尽量停留在当前阅读位置。

底部的进度滑块可以跳到全书任意位置，拖动结束后生效。阅读位置会自动保存，从书架重新打开时会回到上次位置；是否显示底部进度可以在阅读设置里关闭。

文字书为了减少大文件排版等待，会按分段加载。**底部显示的页码是当前加载分段的页码，百分比才是全书进度**；跨过分段时页码可能重新计算。请用百分比判断整体阅读位置。

### 目录与搜索

点击工具栏的目录按钮打开侧栏，可以查看目录层级、章节百分比，并点击章节跳转。当前章节会高亮。没有目录的书籍会显示「这本书没有目录」；PDF 会优先使用出版社目录，没有目录时列出每一页。

点击搜索按钮会在工具栏下方打开「在书中查找…」。输入关键词后会显示匹配数量和当前位置，用「‹」「›」切换上一处或下一处，点「×」关闭。

- 文字书的查找范围是当前已加载的阅读分段，而不是整本电子书。如果找不到目标，可以先用目录或进度条移动到附近位置，再重新搜索。
- PDF 搜索覆盖当前 PDF 文档。
- CBZ 漫画不提供全文搜索。

### 书签与笔记

点击工具栏的书签按钮打开侧栏，侧栏分为「目录」「书签」「笔记」三个标签。

添加书签：

1. 移动到想保留的位置。
2. 打开「书签」标签。
3. 点击「在当前位置加书签」。

如果文字书中当前选中了文字，书签会记录选中的文字片段；否则记录当前位置。书签列表可以「打开」「补写笔记」「删除」。带笔记的书签会显示笔记内容。

添加笔记：

1. 打开「笔记」标签，或在 HTML/PDF 阅读时直接点击工具栏的笔记按钮。
2. 在「写下这一刻的想法…」中输入内容。
3. 点击「保存笔记」。

笔记保存在当前位置关联的书签记录上，可以在「笔记」标签里「打开」「编辑」「删除」。笔记内容也可通过「书签」里的「补写笔记」添加。HTML 和 PDF 的笔记入口最直接；其他格式可以先点书签按钮，再切换到「笔记」标签。

书签和笔记只保存在本机，不会通过 WebDAV 同步到其他设备，也没有单独的导出功能。删除书籍或把它移出书架会同时删除对应的书签和笔记。

### 阅读设置

点击工具栏的文字格式按钮打开「阅读设置」，可以调整：

- 主题：纸白、米黄、浅绿、夜间。
- 字体：宋体、黑体、楷体、系统。
- 字号：15–30 px。
- 行距：1.35–2.2 倍。
- 页边距：3%–16%。
- 翻页方式：左右分页或上下滚动。
- 分栏：自动、单栏、双栏。
- 底部进度显示开关。
- 「使用出版方排版」：仅 EPUB 显示，开启后尽量保留书籍自带的 CSS 与字体；切换后这本书会重新打开。

这些设置会保存在本机并用于之后打开的书籍。字号、行距、页边距、分栏和翻页方式主要作用于文字书；PDF 保持原版面，CBZ 漫画按图片显示。

### PDF 与漫画

PDF 以原始版面滚动阅读，底部的页码和滑块按 PDF 页数计算。带目录大纲的 PDF 会在目录侧栏显示出版社目录，没有目录时按页列出。PDF 也支持搜索、书签和笔记。

损坏的 PDF、加密 PDF 或受 DRM 保护的文件可能无法打开。加密 PDF 与带 DRM 的 Kindle 书也无法参与 WebDAV 同步。

CBZ 漫画按页显示，可以左右滑动、点击页面两侧的箭头或拖动底部滑块翻页。可以切换单页或双页；宽屏首次打开时默认双页。漫画没有目录和全文搜索，但仍然可以通过书签和笔记侧栏记录当前位置。

## WebDAV 书库与同步

WebDAV 书库、云端书架与多设备同步全部免费，不需要购买、授权码或账号。同步数据只发送到你自行填写的 WebDAV 服务器。

### 配置 WebDAV

第一次进入 WebDAV 书库时，如果还没有配置账号，应用会自动打开同步设置；之后也可以点击 WebDAV 标签旁的齿轮图标进入。

1. 选择服务商：坚果云、Nextcloud 或自定义 WebDAV。
2. 填写服务器地址、账号和应用密码。
3. 选择同步目录：「EasyRead（默认）」或「ZenReader（兼容）」。
4. 点击「测试连接」，确认账号可访问、同步目录可用。
5. 点击「保存配置」。

服务器地址只需填写到账号根目录，应用会自动拼接同步目录。参考格式：

- 坚果云：`https://dav.jianguoyun.com/dav/`。选择坚果云后应用会自动填入。账号填坚果云邮箱，密码必须使用「账户信息 → 安全选项」中生成的第三方应用密码，不要使用登录密码。
- Nextcloud：`https://你的域名/remote.php/dav/files/你的用户名/`。在 Nextcloud 的「设置 → 安全」中创建应用密码。
- 自定义 WebDAV：填写服务商提供的 WebDAV 根地址，例如 `https://example.com/dav/`。

应用密码或访问令牌只保存在应用私有目录，并只发送给你填写的 WebDAV 服务器。

「测试连接」会验证账号并准备同步目录（不存在时自动创建）。「保存配置」会保存当前服务器、账号、密码、服务商、同步目录和自动同步开关。「清除配置」只清除这些 WebDAV 凭据，不会删除书架里的书或阅读进度。

### 同步目录怎么选

- **EasyRead（默认）**：只使用 EasyRead 的设备选这个，云端目录为 `EasyRead`。
- **ZenReader（兼容）**：需要与极简阅读或 ZenReader/v1 的云端数据共享时选这个，云端目录为 `ZenReader/v1`。
- 切换目录只影响之后的同步，不会移动或删除另一个目录里已有的文件。

### 同步操作

在 WebDAV 书库中，可以点击标签旁的同步图标、在同步设置里点「双向同步（推荐）」，或下拉书架触发同步。

- **双向同步（推荐）**：合并两端的 WebDAV 书库和阅读进度。每本书以最近阅读时间较新的一侧为准；时间相同或非常接近时，保留进度更大的一侧。本机缺少的云端书会下载到 WebDAV 书架，云端缺少的 WebDAV 书架书会上传。
- **上传覆盖云端**：以本机 WebDAV 书架中已读进度覆盖云端记录，并上传云端缺少的 WebDAV 书架书；不会处理本地书库，也不会下载云端新增书籍。未在本机打开过的书保留云端进度。
- **下载覆盖本机**：下载云端新增书籍到 WebDAV 书架，并用云端有记录的位置替换本机 WebDAV 书架中对应书的进度；不会把本机新书或新进度上传到云端。

单向覆盖只在确定以某一端为准时使用。两台设备同时阅读同一本书时，进度仲裁依赖设备记录的阅读时间，请尽量保持设备时间自动校准。

同步设置里的「启动时自动同步」打开并保存后，应用启动时会检查一次；停留在前台期间，距上次同步超过约 5 分钟还会自动执行双向同步。自动同步依赖应用进程运行，离开应用后不保证继续执行，重要同步请回到应用手动完成。

每次同步只新建一份快照，不覆盖旧快照；没有内容变化时可能不会写入新快照。云端删除也在同步中生效：在一台设备选择「从云端删除并移出书架」后，其他设备同步时会移除这本书。

已经下载到本机的 WebDAV 书可以离线打开阅读；同步、下载新书和上传新书需要网络。

### 哪些书会同步

WebDAV 同步只处理「WebDAV书库」里的书，本地书库中的书不会自动上传，阅读进度也不会自动迁移到云端。想把一本书放到云端，请先切到「WebDAV书库」，用「+」导入这本书，再执行同步；如果同一文件之前只导入过本地书库，重新导入 WebDAV 书架会形成一条新的书籍记录，需要从当前设备重新记录进度。

从 HarmonyOS 上传到 WebDAV 的书籍目前只包括 TXT、EPUB、PDF、MOBI、AZW 和 AZW3。从云端下载还额外支持 Markdown（.md/.markdown），但 Markdown 不会从本机上传。FB2、CBZ、RTF 和 DOCX 不参与 WebDAV 同步，只能在本机导入阅读；如果把它们导入 WebDAV 书架，它们也只保存在本机。

加密 PDF、带 DRM 的 Kindle 书无法同步。书签、笔记、阅读主题和其他设置不会同步；WebDAV 同步的是 WebDAV 书架中的书籍文件和阅读进度。

## 数据、备份与隐私

EasyRead 没有开发者服务器，也没有广告、统计或社交 SDK。书籍副本、封面、阅读进度、书签、笔记和设置都保存在应用沙箱；WebDAV 账号与应用密码也只保存在本机，并只发送给你填写的 WebDAV 服务器。

卸载应用通常会清除应用沙箱中的本地书库、进度、书签、笔记和 WebDAV 配置。请保留原始书籍文件。WebDAV 书架可以作为受支持格式书籍与阅读进度的跨设备备份，但不会备份书签、笔记和阅读设置。

完整说明见 [隐私政策](privacy-policy.md)。

## 常见问题

### 为什么 GitHub 上没有可以下载安装的 HAP？

HarmonyOS 不支持普通用户自由侧载 HAP。安装包必须使用华为开发者证书和匹配的 profile 签名，真机调试还通常需要把设备加入调试 profile。本仓库因此只发布源码，请在 DevEco Studio 中自行签名构建。应用市场分发还需要满足华为的相应要求。

### 同步后进度没有变化

- 双向同步以最近阅读时间为准。旧设备上时间更晚的记录可能覆盖新设备上的位置，请先校准设备时间。
- 确认两台设备连接的是同一个 WebDAV 服务器、账号和同步目录。
- 确认这本书在两台设备上都被打开过，并且确实移动了阅读位置。
- 如果确定要以某一端为准，使用「上传覆盖云端」或「下载覆盖本机」。
- 同步只传书籍和进度，书签和笔记不会出现在另一台设备上。

### 同步失败或连接失败

- 坚果云必须使用第三方应用密码，不能使用网页登录密码。
- 检查服务器地址是否填到了账号根目录，不要把 `EasyRead` 或 `ZenReader/v1` 手动拼进地址。
- Nextcloud 的地址通常包含 `/remote.php/dav/files/用户名/`。
- 检查网络连接和设备时间；部分服务商对应用密码和 WebDAV 权限有单独开关。
- 先点「测试连接」，确认账号可以访问同步目录，再点「保存配置」或开始同步。
- 大书首次上传需要较长时间，请保持应用在前台，等待进度完成。

### 为什么某些书没有出现在另一台设备上？

WebDAV 同步只处理 WebDAV 书架。放在本地书库的书不会自动上传，也不会出现在其他设备。请先切到「WebDAV书库」导入这本书，再同步。

从 HarmonyOS 上传目前只支持 TXT、EPUB、PDF、MOBI、AZW 和 AZW3。Markdown（.md/.markdown）可以从云端下载，但不会从本机上传。FB2、CBZ、RTF 和 DOCX 不参与 WebDAV 同步，只能在本机阅读。加密 PDF 和 DRM Kindle 书也无法同步。

### 删除书会删除原始文件吗？

导入到 EasyRead 的本地书是应用沙箱中的副本。删除本地文件或移出书架不会修改你系统文件管理器里的原文件。WebDAV 的「删除本地副本」也不会删除云端文件；对于已同步到云端的书，只有「从云端删除并移出书架」会写入云端删除快照。无论哪种删除，都会同时移除该书的书签和笔记。
